# Paket Tour Malang Batu City Tour

Jelajahi keindahan kota Malang dan Batu dalam satu hari penuh dengan tur city tour kami. Kunjungi berbagai tempat wisata terkenal dan nikmati kuliner khas Malang.

## Itinerary Hari 1

| Waktu | Kegiatan |
|-------|----------|
| 08:00 | Penjemputan di hotel/area Malang |
| 09:00 | Kunjungi Monumen Tugu Malang |
| 10:00 | Jalan-jalan di Alun-alun Kota Malang |
| 11:00 | Menuju Batu untuk melihat kebun apel |
| 12:00 | Makan siang dengan menu khas Malang |
| 13:00 | Kunjungi Museum Angkut |
| 15:00 | Wisata kebun teh dan strawberry |
| 17:00 | Kembali ke Malang |
