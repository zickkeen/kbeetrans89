# Paket Tour Bromo Snorkling Gili Ketapang (2D1N)

Gabungkan pengalaman sunrise di Gunung Bromo dengan aktivitas snorkling di pantai Gili Ketapang. Paket 2 hari 1 malam yang sempurna untuk pecinta petualangan.

## Itinerary Hari 1: Bromo Sunrise

| Waktu | Kegiatan |
|-------|----------|
| 00:00 | Penjemputan di Surabaya/Malang |
| 02:00 | Tiba di area Bromo, persiapan trekking |
| 03:00 | Naik jeep menuju viewpoint |
| 05:30 | Menyaksikan sunrise spektakuler |
| 07:00 | Tur crater dan pasir berbisik |
| 10:00 | Sarapan dan istirahat |
| 12:00 | Perjalanan ke Gili Ketapang |

## Itinerary Hari 2: Snorkling Gili Ketapang

| Waktu | Kegiatan |
|-------|----------|
| 08:00 | Sarapan pagi di hotel |
| 09:00 | Snorkling di spot terbaik Gili Ketapang |
| 12:00 | Makan siang di pantai |
| 14:00 | Waktu bebas berenang atau berjemur |
| 16:00 | Kembali ke hotel dan persiapan pulang |
| 18:00 | Perjalanan kembali ke Surabaya/Malang |

- Transportasi AC Toyota Hiace/Innova

- Air mineral
