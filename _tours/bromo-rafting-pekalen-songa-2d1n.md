# Paket Bromo – Rafting Pekalen atau Songa (2D1N)

Gabungkan petualangan di Gunung Bromo dengan sensasi rafting di sungai Pekalen atau Songa dalam paket 2 hari 1 malam yang menantang.

## Destinasi

- Sunrise point
- Bukit widodaren
- Pura luhur poten
- Kawah bromo
- Bukit teletabis
- Savana bromo
- Pasir berbisik
- Rafting songa / pekalen

## Penjemputan

- Kota malang
- Surabaya
- Bandara juanda

## Fasilitas

- Transportasi selama perjalanan
- Driver professional
- BBM, parkir
- Jeep bromo
- Tiket masuk bromo
- Hotel di bromo
- Peralatan rafting
- Makan siang setelah rafting
- Dokumentasi rafting
- Snack dan air mineral

## Itinerary

### Hari Pertama

| Waktu | Kegiatan |
|-------|----------|
| 06.00 – 06.30 | Penjemputan di meeting point |
| 06.30 – 09.30 | Perjalanan menuju pos rafting |
| 09.30 – 10.00 | Persiapan rafting |
| 10.00 – 12.30 | Explorer rafting |
| 12.30 – 13.00 | Makan siang |
| 13.00 – 13.30 | Persiapan menuju hotel di bromo |
| 13.30 – 18.00 | Perjalanan menuju hotel bromo |
| 18.00 | Cek in hotel, menikmati sunset di hotel free agenda |

### Hari Kedua

| Waktu | Kegiatan |
|-------|----------|
| 02.00 – 03.00 | Persiapan naik jeep |
| 03.00 – 04.00 | Perjalanan dengan jeep menuju sunrise point |
| 04.00 – 06.00 | Explorer sunrise point, bukit teletabis |
| 06.00 – 08.00 | Explorer bukit widodaren, kawah bromo, savana bromo |
| 08.00 – 10.00 | Explorer pasir berbisik, pura luhur ponten |
| 10.00 – 11.00 | Perjalanan dengan jeep ke rest area bromo |
| 11.00 – 12.00 | Bersih diri dan persiapan perjalanan menuju meeting point |
| 12.00 – 15.00 | Perjalanan dengan mobil pribadi menuju meeting point |
| 15.00 | Finish |
