# Paket Tour Bromo Rafting Pekalen (2D1N)

Rasakan sensasi arung jeram di Sungai Pekalen yang terkenal dengan Grade 2-3, kemudian saksikan sunrise spektakuler di Gunung Bromo dalam paket 2 hari 1 malam.

## Itinerary Hari 1: Rafting Pekalen

| Waktu | Kegiatan |
|-------|----------|
| 08:00 | Penjemputan di Surabaya/Malang |
| 10:00 | Tiba di basecamp rafting Pekalen |
| 11:00 | Safety briefing dan persiapan |
| 12:00 | Mulai arung jeram (±2-3 jam) |
| 15:00 | Selesai rafting, makan siang |
| 17:00 | Perjalanan ke hotel area Bromo |
| 19:00 | Check-in hotel dan makan malam |

## Itinerary Hari 2: Bromo Sunrise

| Waktu | Kegiatan |
|-------|----------|
| 00:00 | Persiapan untuk sunrise Bromo |
| 02:00 | Naik jeep menuju viewpoint |
| 03:00 | Trekking ke spot sunrise |
| 05:30 | Menyaksikan sunrise spektakuler |
| 07:00 | Tur crater dan pasir berbisik |
| 10:00 | Sarapan dan check-out |
| 12:00 | Perjalanan kembali ke Surabaya/Malang |

## Fasilitas Terbaik

- Transportasi AC Toyota Hiace/Innova
- Driver profesional berpengalaman
- Tiket rafting Pekalen lengkap
- Tiket masuk Bromo
- Jeep 4WD untuk akses Bromo
- Guide lokal ahli
- Akomodasi hotel 1 malam
- Peralatan rafting lengkap
- Makan 3x sehari
- Air mineral

## Harga Termasuk

- Transportasi PP Surabaya/Malang - Pekalen - Bromo - Surabaya/Malang
- Tiket rafting Pekalen
- Tiket jeep 4WD Bromo
- Tiket masuk Bromo
- Guide berpengalaman
- Hotel/penginapan 1 malam
- Peralatan rafting
- Makan 3x sehari
- Dokumentasi foto

## Harga Tidak Termasuk

- Pengeluaran pribadi
- Tips untuk guide dan driver
- Souvenir

## Catatan Penting

- Minimum 4 orang peserta untuk rafting
- Wajib bisa berenang
- Kondisi cuaca dapat mempengaruhi aktivitas
- Bawa pakaian ganti
- Usia minimum 12 tahun
- Harga dapat berubah tanpa pemberitahuan sebelumnya
