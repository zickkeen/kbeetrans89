# Paket Tour Bromo Midnight

Rasakan pengalaman tak terlupakan menyaksikan sunrise di Gunung Bromo dengan tur khusus midnight kami. Tur ini dimulai tengah malam untuk mencapai titik terbaik saat matahari terbit.

## Destinasi

- Sunrise point
- Bukit widodaren
- Pura luhur poten
- Kawah bromo
- Bukit teletabis
- Savana bromo
- Pasir berbisik

## Penjemputan

- Kota malang
- Surabaya
- Bandara juanda

## Itinerary

| Waktu | Kegiatan |
|-------|----------|
| 23.00 – 00.00 | Penjemputan di meeting point |
| 00.00 – 02.30 | Perjalanan dengan mobil pribadi menuju rest area bromo |
| 02.30 – 03.00 | Persiapan naik jeep |
| 03.00 – 04.00 | Perjalanan dengan jeep menuju sunrise point |
| 04.00 – 06.00 | Explorer sunrise point, bukit teletabis |
| 06.00 – 08.00 | Explorer bukit widodaren, kawah bromo, savana bromo |
| 08.00 – 10.00 | Explorer pasir berbisik, pura luhur ponten |
| 10.00 – 11.00 | Perjalanan dengan jeep ke rest area bromo |
| 11.00 – 12.00 | Bersih diri dan persiapan perjalanan menuju meeting point |
| 12.00 – 15.00 | Perjalanan dengan mobil pribadi menuju meeting point |
| 15.00 | Finish |
