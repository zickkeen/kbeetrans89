# Paket Tour Bromo – Kawah Ijen (3D2N)

Rasakan petualangan luar biasa dengan mengunjungi dua gunung berapi terkenal di Jawa Timur dalam satu paket tour. Dari sunrise di Bromo hingga blue fire di Kawah Ijen.

## Itinerary Hari 1: Bromo Sunrise

| Waktu | Kegiatan |
|-------|----------|
| 00:00 | Penjemputan di Surabaya/Malang |
| 02:00 | Tiba di area Bromo, persiapan trekking |
| 03:00 | Naik jeep ke viewpoint utama |
| 05:30 | Menyaksikan sunrise spektakuler |
| 07:00 | Tur crater dan pasir berbisik |
| 10:00 | Check-in hotel di area Bromo |
| Sisa hari | Istirahat dan eksplorasi area sekitar |

## Itinerary Hari 2: Kawah Ijen Blue Fire

| Waktu | Kegiatan |
|-------|----------|
| 00:00 | Perjalanan menuju Kawah Ijen |
| 04:00 | Tiba di Paltuding, persiapan trekking |
| 04:30 | Trekking ke puncak Kawah Ijen (3km) |
| 06:00 | Menyaksikan blue fire dan sunrise |
| 08:00 | Tur kawah belerang dan eksplorasi |
| 12:00 | Kembali ke hotel untuk istirahat |
| Sisa hari | Waktu bebas di hotel |

## Itinerary Hari 3: Kembali ke Asal

| Waktu | Kegiatan |
|-------|----------|
| Pagi | Sarapan pagi dan check-out hotel |
| Siang | Perjalanan kembali ke Surabaya/Malang |
| Sore | Tiba di tujuan, tour selesai |

## Fasilitas Terbaik

- Transportasi AC Toyota Hiace/Innova
- Driver profesional berpengalaman
- Tiket masuk semua objek wisata
- Jeep 4WD untuk akses Bromo
- Guide lokal ahli
- Akomodasi hotel/penginapan 2 malam
- Makan 3x sehari sesuai itinerary
- Air mineral selama perjalanan
- Dokumentasi foto
